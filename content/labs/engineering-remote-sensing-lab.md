## Laboratory Overview

The Remote Sensing Lab is part of the Geomatics Department at the College of Engineering. This laboratory provides students with access to computer workstations equipped with remote sensing software for image processing, analysis, and interpretation.

## Purpose

This lab supports remote sensing practical training covering:
- Satellite image processing
- Remote sensing data analysis
- Image interpretation techniques
- GIS integration with remote sensing
- Digital image analysis

## Facilities

- 17 All-in-one desktop computers
- Remote sensing software
- Image processing tools
- Data storage facilities

## Access and Booking

For access to this laboratory or specific equipment, please contact the lab supervisor.

## Software

- Remote sensing image processing software
- GIS software integration
- Data analysis tools
